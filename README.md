# QALQAN · модуль геолокации (без Clockster)

Учёт приходов, уходов и рабочих визитов. Телефон шлёт точки → сервер считает офис / визиты / чистое время → отметки уходят в **Битрикс24**. **2ГИС** — справочник мест; координаты сотрудников туда не отправляются.

## Что умеет этот срез

- Вкладки: **Карта**, **Журнал дня**, **Мои визиты**, **Справочник мест**, **Симулятор телефона**, **Настройки**
- Роли: админ / сотрудник, данные **изолированы по сессии**
- Синхронизация рабочего дня в Битрикс вместо Clockster
- Postgres на publish; локально — память
- Лимиты sync/points/login и проверка настроек

## Запуск

```bash
npm install
export APP_ADMIN_TOKEN='your-local-admin-password'
npm run dev
```

Dev-сервер: `http://127.0.0.1:3847`

## Доступ (public)

- **Админ**: секрет `APP_ADMIN_TOKEN`
- **Сотрудник** (опционально): секрет `EMPLOYEE_PIN_HASHES` — JSON вида `{"e-askar":"salt:hash",...}` (scrypt). Без секрета вход сотрудника на publish выключен.
- Каждая сессия получает свою песочницу данных (не общую базу всех посетителей)

## Битрикс

Секрет `BITRIX_WEBHOOK_URL` — входящий вебхук REST (`timeman`).
Без него отметки пишутся в демо-журнал (mock).

## Стек
