# QALQAN · модуль геолокации (без Clockster)

Учёт приходов, уходов и рабочих визитов для юрфирмы. Телефон шлёт точки → сервер считает офис / визиты / чистое время → отметки уходят в **Битрикс24** (`timeman.open` / `timeman.close`). **2ГИС** — только справочник мест и (по ключу) карта; координаты сотрудников туда не отправляются.

## Что умеет этот срез

- Вкладки: **Карта**, **Журнал дня**, **Мои визиты**, **Справочник мест**, **Симулятор телефона**, **Настройки**
- Алгоритмы: остановки, офис по Wi‑Fi/геозоне, визиты, чистое время
- Синхронизация рабочего дня в Битрикс вместо Clockster
- Симулятор GPS-точек (вместо мобильного трекера на первом этапе)
- Postgres на publish (`cursor-app.json`), локально — память
- Лимиты sync/points и проверка настроек

## Запуск

```bash
npm install
npm run dev
```

Dev-сервер: `http://127.0.0.1:3847`

## Доступ (public)

- **Админ**: секрет `APP_ADMIN_TOKEN` (локально `admin-dev`) — видит всех, настройки, Bitrix sync за любого.
- **Сотрудник**: персональный PIN (демо: Аскар `1111`, Анна `2222`, Нурлан `3333`, Дана `4444`) — только свои данные.
- Вход через `/api/auth/login` с лимитом попыток; сессия в Bearer-токене.

## Битрикс

Секрет `BITRIX_WEBHOOK_URL` — входящий вебхук REST (`timeman`).
Без него отметки пишутся в демо-журнал (mock).

## Стек

Next.js · TypeScript · Tailwind · Leaflet (OSM; MapGL 2ГИС — по API-ключу) · in-memory store для демо

Мобильный трекер и PostgreSQL/PostGIS — следующий этап по IT-инструкции.
