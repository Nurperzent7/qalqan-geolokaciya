# iPhone: установить на один телефон без App Store и без $99

Подходит, когда приложение нужно на одном-двух своих iPhone.
Платный Apple Developer ($99 в год) не нужен: хватает обычного бесплатного Apple ID.

Ограничения бесплатного Apple ID:

- приложение работает **7 дней**, потом его нужно переподписать (5 минут, данные не теряются — они на сервере);
- не больше 3 таких приложений на одном iPhone;
- нужен компьютер с Windows и кабель для первой установки.

Фоновый GPS работает так же, как в версии из App Store.

## Шаг 1. Получить файл .ipa (один раз)

На Windows собрать iOS-приложение нельзя, поэтому сборка идёт в GitHub на бесплатном Mac.

1. Откройте репозиторий на GitHub → вкладка **Actions**.
2. Слева выберите **«iOS IPA без подписи (Sideloadly)»** → кнопка **Run workflow** → **Run workflow**.
3. Подождите 5–15 минут, пока появится зелёная галочка.
4. Откройте этот запуск → внизу **Artifacts** → скачайте **QALQAN-unsigned-ipa**.
5. Распакуйте zip. Внутри будет `QALQAN-unsigned.ipa`.

## Шаг 2. Подготовить компьютер (один раз)

1. Установите **iTunes** с сайта apple.com (версию для Windows, не из Microsoft Store).
2. Установите **Sideloadly**: https://sideloadly.io
3. Подключите iPhone кабелем. На телефоне нажмите **«Доверять этому компьютеру»**.

## Шаг 3. Установить на iPhone

1. Запустите Sideloadly. Вверху должен появиться ваш iPhone.
2. Перетащите `QALQAN-unsigned.ipa` в окно Sideloadly.
3. В поле **Apple account** введите свой Apple ID (можно завести отдельный бесплатный Apple ID только для этого).
4. Нажмите **Start** и введите пароль Apple ID, когда Sideloadly попросит.
5. Дождитесь надписи **Done**.

## Шаг 4. Разрешить запуск на iPhone

1. **Настройки → Конфиденциальность и безопасность → Режим разработчика → Включить** (iOS 16 и новее). Телефон перезагрузится, после перезагрузки подтвердите включение.
2. **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.
3. Откройте QALQAN, войдите (`bx-…` + пароль от админа).
4. **Настройки → QALQAN → Геолокация → Всегда**.
5. В приложении: вкладка **GPS → Включить GPS (фон)**.

## Каждые 7 дней

Через 7 дней приложение перестанет открываться. Чтобы продлить:

1. Подключите iPhone к компьютеру (кабелем или в той же Wi-Fi сети).
2. В Sideloadly снова перетащите тот же `.ipa` и нажмите **Start**.

Переустанавливать с нуля не нужно, вход и настройки сохраняются.
В Sideloadly можно включить автопродление: тогда достаточно, чтобы компьютер был включён и телефон был в той же Wi-Fi сети.

## Если что-то не так

| Проблема | Что сделать |
|----------|-------------|
| Sideloadly не видит iPhone | Переустановить iTunes с apple.com, переподключить кабель, снова нажать «Доверять» |
| Ошибка про Bundle ID | В Sideloadly → Advanced options → поставить галочку изменения Bundle ID |
| Приложение не открывается | Проверить шаг 4 (режим разработчика и «Доверять») или прошло 7 дней |
| GPS не пишет в фоне | Геолокация должна быть **«Всегда»**, режим энергосбережения выключен |
